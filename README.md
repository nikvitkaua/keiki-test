# Keiki - cats.com (Факти про котів для дітей)

## Інструкція щодо локального розгортання

### Крок перший: встановити всі залежності.
```
npm install
```

### Крок другий: запустити проект в режимі розробки.
```
npm run serve
```

### Крок третій: зібрати проект для продакшн версії.
```
npm run build
```

## Використання додатка
- На сторінці логіна /login і введіть ім'я користувача (3-15 латинських літер).
- Після успішного логіна ви будете перенаправлені на сторінку фактів /facts.
- Клацніть на будь-який факт, щоб перейти на сторінку конкретного факту /fact/:id.
- В хедері відображається перша літера імені користувача; за кліком на неї можна вийти з акаунта.
- Також ви можете фільтрувати і сортувати факти за вашим бажанням на сторінці /facts.
